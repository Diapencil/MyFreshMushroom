# 단계 5 — 종균 배양대 제작

## 현재 동작

- 종균 배양대를 클릭하면 오른쪽 아래에 제작 패널이 열린다. 다른 시설이나 빈 땅을 선택하면 닫힌다.
- 발견한 종류 중 실제 레시피가 설정된 버섯만 목록에 표시한다. MVP에는 느타리 레시피 하나만 연결했다.
- 느타리버섯 2개를 소비해 느타리 종균 3개를 즉시 만든다. 비용과 생산량은 `Assets/Data/SpawnRecipes/OysterSpawnRecipe.asset`에서 조정한다.
- `− / +`로 제작 횟수를 조정한다. 패널에 보유 버섯·종균, 1회 비용·생산량, 선택 횟수의 합계를 표시한다.
- 버섯이 부족하거나 결과 종균이 정수 범위를 넘으면 제작 버튼을 비활성화한다. 서비스에서도 같은 조건을 검사한다.
- 성공하면 두 자원 수량을 한 번에 변경한 뒤 UI에 알린다. 실패하면 버섯만 차감되거나 종균만 지급되는 일이 없다.
- 제작 후 수량과 완료 문구를 갱신한다. 추가 재료·대기 시간·별도 화폐는 없다.
- 배양대 패널을 열어도 성장이 계속된다. 성장 시간은 현재 9초다.
- 단계 6의 튜토리얼 활성 상태에서는 안내한 시점에 1회 제작만 허용한다. 두 번째 보너스 수확 후에는 여러 회 제작 제한을 해제한다. 물 주기 재시도 중 종균이 떨어지면 보충용 1회 제작을 허용한다.

## 주요 파일

- `SpawnRecipeData`: 버섯 정의와 1회 비용·생산량 설정.
- `SpawnProductionService`: 발견·레시피 확인, 여러 회 제작 합계·오버플로 검사, 제작 요청 처리.
- `InventoryService`: 버섯 차감과 종균 지급을 하나의 거래로 처리.
- `GameManager`: 레시피와 제작 시스템 연결.
- `SpawnProductionPanel`: 버섯 목록·횟수 조절·합계·제작·피드백 UI.
- `SampleScene`: 제작 패널과 각 컴포넌트 참조 연결. 추가 수동 연결은 없다.

## 직접 확인

1. 새 Play에서 느타리 종균 3개, 버섯 0개를 확인한다. 배양대 클릭 시 느타리 레시피와 버섯 부족 안내가 나오고 제작 버튼이 비활성화되어야 한다.
2. 선반에 종균을 심고 물 없이 수확한다. 버섯 3개·종균 2개가 된다.
3. 배양대에서 1회 제작한다. 버섯 1개·종균 5개로 바뀌는지 확인한다. 이 종균으로 다시 선반에 접종할 수 있다.
4. 버섯을 충분히 모은 뒤 제작 횟수를 2회로 올린다. 버섯 4개 소비·종균 6개 생산 합계를 확인하고 제작한다.
5. UI 버튼을 눌러도 월드 시설 선택이 바뀌거나 종균이 선반에 자동 접종되지 않아야 한다.

검증은 Unity의 기존 참조 설정을 사용한 코드 컴파일과 실제 인벤토리 코드를 실행한 짧은 거래 검사로 제한한다. Unity Play 조작, 레이아웃, 전체 테스트는 실행하지 않는다.
