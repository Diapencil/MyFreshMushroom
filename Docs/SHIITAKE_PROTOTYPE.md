# 표고 재배 프로토타입

느타리 선반 옆에 2×1 표고 통나무 재배대를 임시로 배치했다. 기존 재배·물 주기·수확 서비스를 그대로 사용하며, 시설 건설과 이동은 구현하지 않는다.

## 테스트 설정

- 탐험에서 표고를 발견하면 배양대 목록에 표고 레시피가 열린다.
- 표고버섯 3개 → 표고 종균 3개. 접종에는 종균 1개를 사용한다.
- 개발자 승인 테스트값: 9초 성장, 기본 수확 3개, 성장 2~3단계에서 물 주기를 한 번 하면 5개 수확.
- 통나무 위 임시 성장 그림 4단계를 표시한다. 수확 후 다시 접종할 수 있다.
- 발견 전 통나무를 선택하면 탐험에서 먼저 발견하라는 안내를 표시한다.
- 기존 느타리 튜토리얼을 유지하며 표고 전용 안내 단계는 추가하지 않는다.

## 주요 변경 파일

- `Assets/Data/Mushrooms/ShiitakeMushroom.asset`: 성장 시간·수확량·4단계 그림.
- `Assets/Data/Facilities/ShiitakeLog.asset`: 2×1 통나무 시설, 표고 정의 및 기존 임시 통나무 그림 연결.
- `Assets/Data/SpawnRecipes/ShiitakeSpawnRecipe.asset`: 표고 3개 → 종균 3개.
- `Assets/Art/Prototype/ShiitakeGrowth`: 통나무 그림과 같은 크기·피벗의 성장 오버레이.
- `Assets/Scenes/SampleScene.unity`: 초기 통나무 시설(그리드 원점 11,6), 배양대 레시피 등록.
- `FacilityPanel`: 재배 시설 공통 문구와 미발견 안내.
- `ForestInteractionTests`: 초기 시설 수를 3개로 갱신.

## Unity에서 확인

1. SampleScene을 열고 Play한다. 빠르게 확인하려면 Play 전에 GameManager의 `Enable Tutorial`을 끈다.
2. 탐험에서 표고 3개를 획득하고 숲으로 돌아온다.
3. 종균 배양대를 선택하고 목록의 `표고버섯`을 눌러 종균 3개를 만든다.
4. 느타리 선반 오른쪽 통나무를 선택하고 `종균 심기`를 누른다. 종균이 2개로 줄어드는지 확인한다.
5. 9초 뒤 통나무를 클릭해 표고 3개를 수확한다.
6. 다시 접종하고 성장 2~3단계에 `물 주기`를 누른다. 완전히 자란 뒤 수확량이 5개인지 확인한다.

씬과 데이터 참조는 연결했으므로 추가 수동 연결은 없다. 상태는 Play 세션에만 유지된다.

검증 범위는 런타임 C# 컴파일과 에셋 참조·배치 설정 확인이다. Unity Play와 실제 UI·그림 배치는 직접 검증하지 않았다.
