# 단계 3 — 느타리 접종·성장·수확

## 현재 동작

- 빈 느타리 선반을 클릭하면 선택만 하고 `종균 심기` 버튼을 표시한다. 버튼을 눌렀을 때 종균 1개를 소비하고 접종한다. 종균 부족 시 버튼은 비활성화되며, 다른 시설 선택·선택 해제·성장 중에는 숨긴다.
- 현재 테스트 편의를 위해 성장 시간을 9초로 설정했다. 성장 1~3단계가 각 3초씩 진행되고 4단계에서 수확 가능해진다. 기획상 임시 기본값은 120초다.
- 균사 → 작은 버섯 → 성장한 버섯 → 다 자란 버섯의 임시 스프라이트를 기존 선반 위에 표시한다.
- 선택한 선반의 상태 패널에 성장 단계, 남은 초, 기본 수확량을 표시한다.
- 4단계에서 선반을 클릭하면 버섯 3개가 들어오고 선반은 즉시 빈 상태로 복귀한다. 다시 나타난 `종균 심기` 버튼으로 재접종한다.
- 수확하지 않고 기다려도 자동 수확·부패·추가 수확은 발생하지 않는다.
- 종균이 없으면 접종하지 않고 패널에 `종균이 부족합니다`를 표시한다.
- UI 위 클릭은 기존처럼 월드에 전달하지 않는다. 배양대는 정보 선택만 가능하다.
- 물 주기는 단계 4, 종균 제작은 단계 5, 재배 튜토리얼은 단계 6에서 추가했다. 수확한 버섯으로 종균을 만들어 재배를 반복할 수 있다. 튜토리얼 중에는 안내 순서에 따라 행동을 제한한다.

## 데이터와 시간

`Assets/Data/Mushrooms/OysterMushroom.asset`의 Inspector에서 다음을 조정한다.

- Growth Duration Seconds: `9` (현재 테스트용 설정)
- Base Harvest Yield: `3`
- Growth Stage Weights: `1, 1, 1` (1~3단계 시간 비율)
- Growth Stage Sprites: `Assets/Art/Prototype/Growth`의 단계별 그림 4개

성장 시간·구간·수확량은 접종 시 해당 재배 주기에 복사한다. 이미 자라는 버섯의 값을 바꾸려면 새 주기로 접종해야 한다. 시간은 `GameManager.Update` 한곳에서 `Time.unscaledDeltaTime`으로 갱신한다. 시설 선택이나 패널 표시와 관계없이 성장하며, `timeScale = 0`에서도 계속된다. 향후 탐험 화면도 같은 GameManager를 유지해야 한다.

튜토리얼 메시지 표시 중에는 예외적으로 진행 시간을 멈춘다. 설명의 `계속` 또는 안내한 조작을 완료해야 다시 진행한다.

종료 시 저장과 오프라인 성장은 구현하지 않았다. 현재 Play를 재시작하면 처음부터 시작한다.

## 주요 코드

- `CultivationState`: 접종한 버섯, 경과 시간, 단계, 수확량. UI 표시가 바뀌는 초 또는 단계 경계에서만 변경 알림을 발생시킨다.
- `CultivationService`: 종균 소비·접종·시간 갱신·수확을 처리한다. 잘못된 요청과 중복 요청을 거부하며, 수확량을 인벤토리에 넣지 못하면 작물을 유지한다.
- `GameManager`: 기존 초기 상태와 함께 재배 시스템을 생성하고 실행 중 시간을 전달한다.
- `FacilityState`: 시설별 재배 상태를 보유한다.
- `FacilityView`: 상태에 따라 성장 그림을 바꾼다.
- `WorldInteractionController`: UI 차단·시설 선택·수확을 처리하며, 선반 클릭으로 접종하지 않는다. 기존 `TrySelectAtScreenPosition`은 선택만 수행한다.
- `FacilityPanel`: 선택한 작물의 상태와 인벤토리 변경을 관찰하고, `종균 심기` 버튼에서 재배 서비스에 접종을 요청한다.

## Unity 연결

SampleScene의 기존 GameManager, World Input, Facility Panel에 참조를 연결했다. 수동으로 추가 연결할 사항은 없다. 기존 컴포넌트·씬·데이터 GUID는 유지했다.

Facility Panel에 Inoculate Button을 연결했다. 보유량·시설 정보·버튼 모두 `KoreanUiFont`를 통해 설치된 시스템 한글 폰트를 사용한다. OS 폰트 파일은 프로젝트에 복사하지 않는다. 현재 보이는 UI 문구와 데이터의 표시 이름은 한글이며, 버섯·시설 ID는 유지한다.

## 직접 확인

1. SampleScene을 다시 열고 Play. 중앙 선반을 클릭해도 종균은 3개 그대로이고 `종균 심기` 버튼이 나타나는지 확인한다. 버튼을 누르면 종균 `3 → 2`, `성장 1/4단계`가 표시되고 버튼은 숨겨진다.
2. 3초·6초·9초 경과 시 단계와 외형이 바뀌는지 확인한다. 다른 시설이나 빈 땅을 선택해도 성장은 계속돼야 한다.
3. `수확 가능` 상태에서 선반을 클릭해 버섯 `0 → 3`, 선반 `빈 선반`, 버튼 재표시를 확인한다. 선반을 다시 클릭해도 자동 접종되지 않고, 버튼을 눌러야 종균 `2 → 1`로 새 재배를 시작한다.

성장 시간을 조정할 때는 Play 전에 느타리 데이터를 변경한다. 현재 9초 설정은 개발자의 테스트용 선택으로 유지한다.

자동 검증은 컴파일과 핵심 재배 테스트 3개로 제한한다. 전체 테스트·장시간 플레이·시각 검증은 실행하지 않는다.

2026-11-07: Unity 6000.3.19f1에서 컴파일 및 `CultivationServiceTests` 3개 통과. 기존 검증용 캐시를 사용했고 결과는 `Logs/Stage3-EditMode.xml`에 있다. 실제 Play 조작과 외형·패널 배치는 직접 확인하지 않았다.
