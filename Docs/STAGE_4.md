# 단계 4 — 물 주기

- 빈 선반의 `종균 심기`로 재배를 시작한다. 성장 시간은 테스트용 9초를 유지한다.
- 성장 2~3단계에 선택한 선반의 정보 패널에 `물 주기` 버튼이 나타난다. 현재 구간 비율에서는 접종 약 3초 후부터 9초 전까지다.
- 물은 한 접종당 한 번만 줄 수 있고 자원을 소비하지 않는다. 1단계·수확 가능 상태·빈 시설·배양대에서는 사용할 수 없다.
- 사용하면 버튼이 사라지고 `물 주기 완료`와 예상 수확량 5개가 표시된다. 선택을 바꾸어도 물 주기 상태는 유지된다.
- 물을 주지 않으면 기존대로 3개를 수확한다. 물을 준 경우 3 × 1.5를 올림하여 5개를 수확한다. 성장 속도는 바뀌지 않는다.
- 수확과 재접종 시 물 주기 상태를 초기화한다. 다음 주기에도 다시 물을 줄 수 있다.
- Inspector의 느타리 데이터 `Watering Yield Multiplier`에서 배율을 조정한다. 배율과 보너스 수확량은 접종할 때 해당 주기에 반영한다. 비정상 배율이나 정수 범위를 넘는 수확량 설정으로는 접종할 수 없다.

## 변경 위치

- `MushroomData`: 배율과 데이터 유효성 검사.
- `CultivationState`: 물 주기 가능 여부·사용 여부·보너스 수확량.
- `CultivationService.TryWater`: 시설·단계·중복 사용 검사 후 물 주기 적용.
- `FacilityPanel`: 버튼 표시·서비스 요청·완료 상태 표시.
- `SampleScene`: Water Button을 연결했다. 추가 수동 연결은 없다.

## 직접 확인

1. SampleScene을 다시 열고 Play. 선반 선택 후 `종균 심기`를 누른다.
2. 약 3초 뒤 `물 주기`가 나타나면 누른다. 예상 수확량 5개와 완료 문구를 확인한다.
3. 9초가 지난 뒤 선반을 클릭해 버섯 5개 획득을 확인한다.
4. 다시 접종한 뒤 물을 주지 않고 수확해 이번에는 3개가 들어오는지 확인한다.

단계 6에서 튜토리얼 진행 제어를 연결했다. 튜토리얼 활성 상태에서는 첫 주기에 물을 줄 수 없고, 종균 제작 후 두 번째 재배에서 물 주기를 안내한다. 물 주기만 독립적으로 확인하려면 Play 전에 GameManager의 `Enable Tutorial`을 끈다.

검증은 Unity에서 사용하는 C# 컴파일러와 기존 참조 설정을 이용한 코드 컴파일 확인으로 제한했다. 단계별 물 주기·중복 방지·초기화 테스트 사례는 추가했지만 이번에는 실행하지 않았다. 실제 Play 확인도 하지 않았다.
