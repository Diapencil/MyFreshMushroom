# 단계 6 — 재배 튜토리얼

## 구현 범위

- 안내가 필요할 때만 메시지를 상단 중앙에 표시하고, 클릭할 시설·버튼을 제외한 주변을 반투명 검정으로 어둡게 한다. 선택한 시설의 노란 테두리는 유지한다.
- 안내 표시 중에는 성장이 멈추고, 밝은 영역에서만 조작할 수 있다. 시설을 선택하면 밝은 영역이 다음에 누를 버튼으로 이동한다.
- 성공한 행동을 받아 `ProgressState.CurrentTutorialStep`을 진행한다. 버튼을 누르기만 하거나 자원 수량이 우연히 같아졌다고 진행하지 않는다.
- 대상 시설과 재배 주기 번호를 확인해 첫 주기와 두 번째 주기의 수확을 구분한다.
- 단계 7의 시설 건설·이동·철거는 보류한다. 다음 개발 대상은 단계 8의 첫 탐험이다.

## 순서와 기본 수량

1. 선반 선택 후 `종균 심기`: 종균 3 → 2.
2. 첫 주기는 물 주기를 허용하지 않는다. 9초 후 수확: 버섯 0 → 3.
3. 배양대에서 느타리 종균을 1회 제작: 버섯 3 → 1, 종균 2 → 5.
4. 선반에 두 번째 접종: 종균 5 → 4.
5. 성장 2~3단계에 물 주기: 예상 수확량 5개.
6. `6/7 · 물 주기 완료`: 보너스를 확인하고 `계속`을 눌러 성장을 재개한다. 안내를 닫으면 기다리는 동안 메시지는 표시하지 않는다.
7. 다 자랐을 때만 `7/7 · 보너스 수확`을 표시한다. 두 번째 수확으로 버섯 1 → 6이 되고 첫 탐험 대기 상태로 진행한다.

첫 탐험에서 표고를 발견·획득해야 전체 튜토리얼이 완료된다. 단계 8에서 탐험을 연결했다. 재배 안내 후 `계속`을 누르면 재배·제작 제한을 풀고 탐험할 수 있으며, 표고 획득 성공 시 `Completed`로 진행한다.

## 진행 보호와 안내 일시정지

- 안내 전의 추가 접종·제작, 다른 선반의 접종, 첫 주기의 물 주기는 서비스에서 거부한다. UI도 같은 가능 여부를 사용한다.
- 첫 종균 제작의 횟수는 1회로 제한한다. 이후 물 주기 완료까지 불필요한 추가 제작을 막는다.
- 두 번째 접종 후 1단계는 평소 화면에서 성장한다. 2단계에 진입하는 순간 물 주기 안내를 표시하고 성장을 멈춘다. 긴 프레임이 와도 2단계를 건너뛰지 않도록 시간 갱신량을 제한한다.
- 물 주기 안내는 `물 주기`를 실제 완료해야 다음으로 넘어간다. 안내를 읽다가 물 주기 시기를 놓칠 수 없으므로 실패·재시도 메시지와 종균 보충 분기를 제거했다.
- 성장을 기다리는 설명과 마지막 안내에는 `계속` 버튼을 표시한다. 버튼을 누르면 메시지와 어두운 영역이 사라지고 시간이 다시 흐른다.
- 재배 안내 이후에는 일반 재배·물 주기·여러 회 제작 규칙으로 돌아간다.

## 코드와 Unity 설정

- `TutorialManager`: 진행 순서, 대상·주기 확인, 안내 문구, 일시적인 행동 제한.
- `IGameplayActionRules`: 재배·제작 서비스가 행동 제한을 확인하는 공통 계약.
- 재배 서비스의 `Inoculated`, `Watered`, `Harvested`와 제작 서비스의 `Produced`는 성공한 상태 변경 이후에 알린다. 수확 결과에는 시설·주기·버섯 ID·수량·물 주기 여부를 담는다.
- `GameManager`: 튜토리얼과 서비스 생성·연결·정리. `Enable Tutorial`을 끄면 일반 플레이로 시작할 수 있다. 테스트용 옵션이며 플레이 중 전환 기능은 아니다.
- `TutorialPanel`: 클릭 대상의 화면 영역을 계산하고, 네 개의 UI 사각형으로 주변을 어둡게 한다. 어두운 부분은 클릭을 차단하며 밝은 부분은 기존 시설·버튼의 입력을 그대로 사용한다. SampleScene에 참조를 연결했다. 추가 수동 연결은 없다.
- 메시지 위치는 `Tutorial Panel / Tutorial Overlay / Tutorial Message`의 RectTransform에서 조정한다. 현재 상단 중앙이며, 배경 이미지의 Alpha는 0.55다.
- 기존 시설·재배 패널은 튜토리얼 단계 변경도 관찰해 버튼 상태를 갱신한다.

저장 기능은 아직 없으므로 새 Play마다 튜토리얼도 처음부터 시작한다. 성장 시간 9초와 현재 비용·수확량은 유지했다.

## 확인 방법

1. SampleScene을 다시 열고 Play해 밝은 영역을 따라 첫 접종·수확·종균 제작·두 번째 접종을 진행한다. 다른 곳을 눌러도 조작되지 않아야 한다.
2. 첫 재배에는 물 주기 버튼이 없고, 첫 수확 후 종균 제작 전에는 다시 심을 수 없는지 확인한다.
3. 두 번째 물 주기 안내에서 잠시 기다린다. 성장 시간이 그대로이며, 선반 선택 후 실제 물 주기를 해야 다음 안내로 넘어가는지 확인한다.
4. 성장을 기다리는 안내의 `계속`을 눌렀을 때 화면이 원래대로 돌아오고 성장이 재개되는지 확인한다.
5. 두 번째 보너스 수확 후 `재배 안내 완료 · 첫 탐험 대기`의 `계속`을 누르면 자유 재배·제작이 되는지 확인한다.

검증은 코드 컴파일과 실제 진행·재배·제작 소스를 사용하는 짧은 상태 전환 검사로 제한한다. 해당 검사에서는 Unity 에셋 로딩 대신 간단한 데이터 대역을 사용한다. Unity Play, UI 배치와 강조 표시는 직접 확인하지 않았다.

2026-11-07: 컴파일 성공. 메시지 일시정지·재개, 큰 시간 갱신에서도 물 주기 단계 정지, 물 주기 완료 전 안내 유지, 재배 안내 이후 제한 해제 검사 통과. 실제 Play와 강조 영역의 시각 검증은 미실행.
